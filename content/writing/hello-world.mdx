More and more people ask an AI assistant instead of typing into a search box. That changes what "being findable" means for a personal site.

## What did I change?

1. **Everything is in the HTML.** Pages are statically generated, so crawlers that don't run JavaScript still see all the content.
2. **A Markdown version of every page.** Append `.md` to any project or post URL, or read [/llms.txt](/llms.txt).
3. **One entity, one graph.** Every page's JSON-LD points to the same `Person` node, with links to my other profiles.
4. **Answer-first writing.** Each case study opens with a one-sentence TL;DR and quantified outcomes.
