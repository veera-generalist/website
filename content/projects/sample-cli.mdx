## What problem did this solve?

Setting up a new static site meant copying config between repos and clicking through a hosting dashboard. I wanted one command from zero to deployed.

## How did I approach it?

- A small, dependency-light CLI written in TypeScript.
- Templates pulled from a GitHub repo, so new ones don't need a release.
- A GitHub Actions workflow generated for every new project.

## What were the results?

The project reached 1.2k stars on GitHub and 300+ weekly downloads on npm.
